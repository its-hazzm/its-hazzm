### 🚀 Featured Engineering Projects

#### 📱 [Sadaqah App](https://github.com/its-hazzm/Sadaqah-Gaza) – Offline-First Mobile Application
* **Stack:** React Native, Expo, SQLite, JavaScript.
* **Core Engineering:** Designed and engineered a standalone offline-first Quran reader built to function reliably during total power cuts and communication blackouts.
* **Database & Indexing:** Implemented a local SQLite database with custom indexing to eliminate memory bottlenecks and avoid linear table scans on resource-constrained Android devices.
* **Search Normalisation:** Built an Arabic text normalisation algorithm that strips diacritics for rapid, local query matching without server dependencies.
* **Status:** Production build completed and submitted to Google Play (Currently under review).

#### 🎬 "Hazem in the War" – Independent Documentary Series
* **Platform:** Published independently on Instagram.
* **Overview:** Authored, directed, and produced an independent documentary series chronicling student resilience and the continuation of education during wartime in Gaza.
* **AI Production Workflow:** Deployed an end-to-end generative AI production pipeline for visual and audio scene generation to overcome severe camera, filming equipment, and electricity shortages.
* **Lifecycle:** Managed the full production lifecycle from original narrative writing and storyboarding to final post-production and digital distribution.
